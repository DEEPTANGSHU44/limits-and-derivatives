The mathematics of instantaneous change.

THE CENTRAL IDEA

What is a derivative?

A derivative measures how rapidly a quantity changes with respect to another quantity.

Δy / Δx
→
dy / dx

FIRST PRINCIPLES

The derivative from the definition

The derivative is itself built from a limit.

f′(x) = lim h → 0 [f(x+h) − f(x)] / h

For example, let

f(x) = x²

Then:

f′(x) = lim h → 0 [(x+h)² − x²] / h
= lim h → 0 [2xh + h²] / h
= lim h → 0 (2x+h)
∴   f′(x) = 2x
